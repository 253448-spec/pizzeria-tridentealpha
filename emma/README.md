# Emma — Scrum Master

## ¿Qué es un Scrum Master?
Es la persona que organiza al equipo, se asegura de que todos sepan qué hacer
y junta el trabajo de todos al final. No es "el jefe", es el que facilita.

## ¿En qué rama trabajas?
En `main`, porque tú eres la que integra el trabajo de los demás.
Eres la única que puede tocar `main`.

## ¿Qué archivos son SOLO tuyos?
- `backend/server.js` → el programa principal del backend
- `backend/package.json` → la lista de dependencias del backend
- `docs/sprints.md` → el cronograma de sprints
- `docs/sprint-1.md`, `sprint-2.md`, `sprint-3.md` → detalle de cada sprint
- `db/schema.sql`   
- `emma/integracion.md` → los pasos para juntar las ramas
- `emma/documento-final.md` → el documento para la maestra

## ¿Qué NO debes tocar?
- `backend/martin/`, `backend/mario/`, `frontend/`, `db/schema.sql`
  Esos son de tus compañeros.
