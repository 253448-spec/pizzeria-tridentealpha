# Pizzería — Sistema de Gestión
**Equipo:** Tridente Alpha
**Entrega final:** 31 de octubre

## Problema
Pedidos en Excel y a lápiz, una sola PC, sin registro de clientes ni reportes.

## Solución
App de gestión de pedidos, clientes y reportes básicos.

## Reglas del equipo
1. **Nadie toca `main`.** Cada uno crea su rama y trabaja ahí.
2. Cada uno lee el `README.md` y el `sprint-1.md` de su carpeta.
3. Emma (Scrum Master) une todas las ramas al final.

## Equipo y Carpetas
*   **Sam** (PO) -> Carpeta: `sam/`
*   **Emma** (SM) -> Carpeta: `emma/` y `backend/server.js`
*   **Emiliano** (Front) -> Carpeta: `frontend/`
*   **Martin** (API) -> Carpeta: `backend/martin/`
*   **Mario** (API) -> Carpeta: `backend/mario/`
*   **Carlitos** (BD/QA) -> Carpeta: `db/`

## Estructura del proyecto
*   `docs/` → Sprints, backlog, contrato API, pruebas.
*   `emma/` → Scrum Master (integración y documento final).
*   `sam/` → Product Owner.
*   `db/` → Base de datos y QA.
*   `backend/` → Código del servidor (dividido en `martin/` y `mario/`).
*   `frontend/` → Pantallas HTML/CSS.
