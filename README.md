Enfoque actual: **MVP (Producto Mínimo Viable)** en un único Sprint.

## Estructura del Proyecto
*   `/docs`: Documentación general (Backlog, Sprints, Contratos API).
*   `/gaby`: Archivos de gestión del Product Owner.
*   `/emmanuel`: Archivos de gestión del Scrum Master e integración.
*   `/frontend`: Código y tareas de la interfaz de usuario.
*   `/backend`: Lógica del servidor, rutas API y lógica de negocio.
*   `/db`: Esquemas SQL, scripts de base de datos y pruebas de calidad.

## Reglas Generales del Repositorio
1. Cada quien trabaja ÚNICAMENTE en su carpeta asignada.
2. No subir código directo a `main` sin revisión (hacer Pull Requests).
3. Hacer `git pull origin main` antes de empezar a trabajar para evitar conflictos.
4. El Login y las contraseñas quedan fuera de este Sprint.
