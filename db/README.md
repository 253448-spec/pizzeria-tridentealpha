# Carpeta de Base de Datos (Carlitos y Emmanuel)

## ¿Qué hace este rol?
Diseñar las tablas y asegurar que el backend pueda guardar los datos de manera correcta.

## ¿Dónde trabajan?
SOLO dentro de `db/`.

## ¿Cómo entregar?
1. Crear una rama: `feature/db-carlitos`.
2. Guardar los archivos.
3. Control de código fuente → mensaje "Esquema de base de datos" → Confirmar → Publicar rama.
4. Avisar en el grupo.
