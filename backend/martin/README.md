# Martin — APIs de pedidos y clientes

## ¿Qué es una API?
Es la parte del programa que recibe pedidos de información y responde.
Por ejemplo: el frontend (pantallas) le dice a la API "guarda este pedido"
y la API lo guarda y responde "listo".

## ¿Qué es un endpoint?
Es una "dirección" dentro de la API. Ejemplo: `/pedido` es el endpoint
para crear o consultar pedidos. `/cliente` es el endpoint para clientes.

## ¿Qué es un router?
Es un archivo que agrupa varios endpoints relacionados. Tú vas a hacer
dos routers: uno para pedidos y uno para clientes.
