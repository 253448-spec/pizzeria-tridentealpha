# Carpeta del Developer de APIs de pizzas, descuentos y reportes

## ¿Qué es una API?
Es la parte del programa que recibe pedidos de información y responde.
El frontend le pide datos a la API y la API los devuelve.

## ¿Qué es un endpoint?
Una "dirección" dentro de la API. Ejemplo: `/pizzas` devuelve la lista
de pizzas disponibles.

## ¿Qué es un router?
Un archivo que agrupa varios endpoints relacionados.
