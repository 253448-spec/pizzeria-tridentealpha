# Carpeta del Backend (Martin y Mario)

## ¿Qué es el backend?
Es la parte del programa que el usuario NO VE: la lógica del servidor, la creación de APIs y el manejo de datos.

## ¿En qué rama trabaja cada uno?
- Martin: `feature/backend-martin`
- Mario: `feature/backend-mario`

## ¿Dónde trabajan?
SOLO dentro de su carpeta (`backend/martin/` o `backend/mario/`).

## Reglas generales
- Guiarse por `docs/contrato-api.md`.
- No tocar `frontend/` ni `db/`.
