# Sprint 1 — Sam (Frontend - Pantalla de Cocina)

## ¿Qué debes hacer?
Crear la pantalla que el cocinero verá. Debe ser **SOLO LECTURA** (no tiene botones ni campos de texto, porque el cocinero no debe tocar la computadora por higiene).

## Fecha límite
31 de octubre, 6 pm.

## ¿Qué archivos debes crear dentro de `frontend/`?
- `cocina.html`
- `cocina.css`

## ¿Qué debe tener `cocina.html`?
- Un título grande: "PANTALLA DE COCINA - PEDIDOS EN HORNO".
- Una lista de tarjetas (cada tarjeta es un pedido). Cada tarjeta debe mostrar en texto GRANDE:
  *   Número de folio (Ej. #01)
  *   Tipo de pizza (Ej. Hawaiana)
  *   Horno asignado (Ej. Horno 1)
  *   Tiempo restante (Ej. 20:00, solo visual)
- **No debe tener botones ni inputs.**

## ¿Qué debe tener `cocina.css`?
- Tipografía muy grande (mínimo 24px para el texto normal, 48px para el título).
- Colores contrastantes (fondo oscuro con letras claras, o viceversa).
- Que se lea desde 2 metros de distancia.

## ¿Cómo entregar?
1. En VS Code, crear una nueva rama: `feature/frontend-sam`.
2. Guardar los archivos (Ctrl+S).
3. Control de código fuente → mensaje "Pantalla de cocina creada" → Confirmar → Publicar rama.
4. Avisar en el grupo.

## Regla
NO toques `frontend/venta.html` ni `frontend/admin.html` (eso es de Emiliano).
