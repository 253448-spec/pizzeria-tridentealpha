# Carpeta del Developer de Frontend

## ¿Qué es el frontend?
Es la parte del programa que el usuario VE y USA: pantallas, botones,
formularios. Es lo contrario del backend (que no se ve pero guarda datos).

## ¿Qué es HTML y CSS?
- **HTML** → la estructura de la pantalla (títulos, campos, botones).
- **CSS** → los colores, tamaños y estilos.
