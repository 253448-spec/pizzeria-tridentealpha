# Carpeta de los Developers de Frontend (Sam y Emiliano)

## ¿Qué es el frontend?
Es la parte del programa que el usuario VE y USA: pantallas, botones, formularios.

## ¿Qué es HTML y CSS?
- **HTML** → la estructura de la pantalla (títulos, campos, botones).
- **CSS** → los colores, tamaños y estilos.

## ¿Dónde trabaja este rol?
SOLO dentro de `frontend/`. No tocar `backend/` ni `db/`.

*   Emiliano: `feature/frontend-emiliano`
