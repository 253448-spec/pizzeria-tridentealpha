# Product Backlog — Pizzería Tridente Alpha

## ¿Qué es el backlog?
Es una lista ordenada de todo lo que el sistema debe hacer. Cada cosa de la lista es una "historia de usuario".

| # | Historia | Criterio de aceptación | Prioridad |
|---|---|---|---|
| 1 | Registrar pedido | Dado un cliente y una pizza, cuando guardo el pedido, entonces aparece en la lista con el total correcto. | Alta |
| 2 | Registrar cliente | Dado un nombre y teléfono, cuando guardo el cliente, entonces aparece en la lista y se puede elegir en un pedido. | Alta |
| 3 | Aplicar descuento estudiante | Dado un cliente marcado como estudiante, cuando se calcula su total, entonces se le aplica un 10% de descuento. | Media |
| 4 | Reporte de pizzas más vendidas | Dado un historial de pedidos, cuando consulto el reporte, entonces veo cuántas pizzas de cada tipo se vendieron. | Media |
| 5 | Historial de pedidos | Dado un día de ventas, cuando consulto el historial, entonces veo la lista de pedidos ordenada por fecha. | Baja |
